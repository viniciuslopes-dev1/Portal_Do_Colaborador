# Pedido para iniciar o projeto

Copie a mensagem abaixo no novo chat, com esta pasta aberta:

> Leia integralmente AGENTS.md, README.md, docs/DECISOES.md, docs/PROGRESSO.md e docs/HISTORICO.md. Consulte os requisitos, a arquitetura e a lógica documentados. Quero começar do zero pela Etapa 01, sem reutilizar o protótipo. O sistema não terá matrícula: funcionario_id será automático e permanente; o login será pelo e-mail corporativo Google. Explique a arquitetura, destaque decisões pendentes e me oriente nas configurações do novo ambiente. Tenho conhecimentos básicos de HTML, CSS e JavaScript e estou aprendendo Apps Script. Agrupe instruções práticas, sem fragmentar demais. Implemente somente a etapa autorizada, teste, documente e aguarde minha autorização antes da próxima. Não crie todas as telas agora.

Não cole senhas, tokens ou chaves no chat. O domínio, as contas e as permissões do ambiente novo devem ser confirmados durante a preparação.
